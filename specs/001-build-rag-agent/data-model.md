# Data Model: RAG Agent with OpenAI SDK

## Entities

### Agent Request
**Description**: A query or question submitted to the RAG agent
- **query**: string - The question or query text from the user
- **timestamp**: datetime - When the request was made
- **user_context**: dict - Optional context about the user making the request

### Retrieved Content Chunks
**Description**: Segments of book content retrieved from Qdrant based on semantic similarity to the query
- **content**: string - The actual text content retrieved from the vector store
- **source_url**: string - The URL where the original content was sourced from
- **title**: string - The title of the source document
- **section**: string - The section of the document where this chunk originated
- **chunk_index**: integer - The position of this chunk within the original document
- **score**: float - The similarity score for this retrieval result
- **metadata**: dict - Additional metadata associated with the chunk

### Agent Response
**Description**: The final answer generated by the agent based on retrieved content
- **response**: string - The agent's answer to the user's query
- **confidence**: float - Confidence score based on content match quality
- **sources**: list - List of source URLs used to generate the response
- **timestamp**: datetime - When the response was generated
- **query_used**: string - The original query that generated this response

### Retrieval Tool
**Description**: The mechanism that connects to Qdrant and retrieves relevant content chunks
- **query_vector**: list[float] - The embedding vector representation of the query
- **top_k**: integer - Number of top results to retrieve
- **search_results**: list[Retrieved Content Chunks] - Results from the vector search
- **execution_time**: float - Time taken to execute the retrieval
